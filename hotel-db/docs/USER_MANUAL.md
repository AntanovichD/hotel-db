# Инструкция пользователя

Информационная система «Гостиница — учёт заселения и освобождения номеров».

## 1. Установка серверной части

### 1.1 MS SQL Server

1. Скачать **SQL Server 2019 Express** или **Developer** с сайта Microsoft и установить с настройками по умолчанию (тип установки «Basic»). Развернётся именованный экземпляр `SQLEXPRESS` (Express) или `MSSQLSERVER` (Developer).
2. Скачать и установить **«Microsoft ODBC Driver 18 for SQL Server»** (для подключения из Python).
3. Установить **SQL Server Management Studio (SSMS)** — графический клиент.
4. (Только для Express) Включить смешанную аутентификацию SQL и/или TCP/IP в SQL Server Configuration Manager, перезапустить службу `SQL Server (SQLEXPRESS)`.

### 1.2 Создание базы данных

В SSMS подключиться к серверу и **последовательно** выполнить скрипты из папки `sql`:

| № | Файл | Назначение |
|---|------|------------|
| 1 | `01_create_database.sql` | создание базы `HotelDB` с кодировкой `Cyrillic_General_CI_AS` |
| 2 | `02_create_tables.sql`   | таблицы и ограничения целостности |
| 3 | `03_views.sql`           | представления |
| 4 | `04_functions.sql`       | пользовательские функции |
| 5 | `05_procedures.sql`      | хранимые процедуры |
| 6 | `06_triggers.sql`        | триггеры |
| 7 | `07_seed_data.sql`       | тестовые данные |

Можно выполнить один файл `sql/run_all.sql` в режиме «SQLCMD Mode» (меню *Query → SQLCMD Mode*).

После выполнения в базе должно быть: 7 таблиц, 4 представления, 4 функции, 4 хранимые процедуры, 4 триггера.

## 2. Настройка клиентской части

### 2.1 Установка Python и зависимостей

```bat
py -3.11 -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
```

### 2.2 Файл .env

Скопировать `.env.example` → `.env` и заполнить:

```dotenv
HOTEL_DB_SERVER=localhost\SQLEXPRESS
HOTEL_DB_NAME=HotelDB
HOTEL_DB_DRIVER=ODBC Driver 18 for SQL Server
HOTEL_DB_TRUSTED=yes
HOTEL_DB_TRUST_CERT=yes
```

Для логина SQL вместо `Trusted_Connection` указать:

```dotenv
HOTEL_DB_TRUSTED=no
HOTEL_DB_USER=sa
HOTEL_DB_PASSWORD=<ваш_пароль>
```

### 2.3 Запуск

```bat
python -m app.main
```

Откроется главное окно «Журнал заселений».

## 3. Работа с программой

### 3.1 Главное окно — Журнал

- Таблица показывает текущие активные заселения (двойной клик по строке открывает форму выселения).
- Кнопка **«Показать всю историю»** переключает в режим полной истории заселений.
- Поле «Поиск» фильтрует журнал по ФИО, паспорту, номеру комнаты или ФИО сотрудника.
- Меню **«Файл → Обновить»** или клавиша `F5` — ручное обновление.

### 3.2 Заселение гостя

Меню **«Операции → Заселить гостя»** (или кнопка «Заселить»). В форме:

- автоматически предлагаются только свободные номера;
- выбор гостя (либо сначала добавить нового через «Справочники → Гости»);
- выбор сотрудника, оформляющего заселение;
- плановая дата выселения (формат `ДД.ММ.ГГГГ`);
- комментарий.

Сохранение вызывает хранимую процедуру `sp_CheckInGuest`. Триггер `tr_Stays_AfterInsert` автоматически переводит номер в статус «Занят».

### 3.3 Выселение гостя

Выбрать активное заселение в журнале → кнопка **«Выселить»** (или двойной клик по строке).

Форма выселения:
- показывает данные текущего проживания;
- блок «Дополнительные услуги» позволяет добавить услуги (хранимая процедура `sp_AddStayService`);
- кнопка **«Выселить и рассчитать стоимость»** вызывает `sp_CheckOutGuest`, заполняет дату выселения и сохраняет итоговую стоимость (функция `fn_CalculateStayCost`).

Триггер `tr_Stays_AfterCheckOut` автоматически освобождает номер.

### 3.4 Справочники

Меню **«Справочники»** содержит:
- Категории номеров;
- Номера;
- Гости;
- Сотрудники;
- Дополнительные услуги.

Каждая форма содержит таблицу слева и форму редактирования справа. Кнопки **«Добавить»**, **«Изменить»**, **«Удалить»**. Клик по строке таблицы заполняет форму. Все изменения сразу отражаются в журнале без перезапуска приложения.

### 3.5 Отчёт за период

Меню **«Отчёты → Отчёт за период»**.

Поля формы:
- *Дата с / Дата по* — выбор интервала;
- *Категория* — выпадающий список (или «Все»);
- *Сотрудник* — выпадающий список (или «Все»).

Кнопка **«Сформировать»** вызывает процедуру `sp_GetReportByPeriod` и рассчитывает заполняемость функцией `fn_GetOccupancyRate`. В нижней строке появляются итоги: количество записей, общая выручка и заполняемость номерного фонда (%).

Кнопка **«Экспорт в Word»** сохраняет отчёт в `.docx` (форматированная таблица с заголовком, итогами и параметрами).

Кнопка **«Печать»** формирует временный `.docx` и отправляет его на принтер по умолчанию (через системный механизм Word/`lp`).

## 4. Возможные ошибки и их решение

| Сообщение | Причина | Решение |
|-----------|---------|---------|
| «Не удалось подключиться к БД» | неверные параметры в `.env`, сервер не запущен | проверить `services.msc`, путь к экземпляру (`localhost\SQLEXPRESS`), TCP/IP в SQL Server Configuration Manager |
| «Driver does not support …» | не установлен ODBC Driver 18 | установить `msodbcsql18` |
| «В этом номере уже проживает гость» | сработал триггер `tr_Stays_PreventOverlap` | оформить выселение текущего гостя или выбрать другой номер |
| «Невозможно удалить категорию» | сработал триггер `tr_RoomCategories_PreventDelete` | сначала переназначить или удалить связанные номера |

## 5. Соответствие требованиям задания

| Требование | Реализация |
|-----------|-----------|
| Не менее 7 таблиц | 7 таблиц в `sql/02_create_tables.sql` |
| Первичные ключи числовые, автоинкрементные | `IDENTITY(1,1)` во всех таблицах |
| Ограничения целостности (FK, CHECK) | присутствуют во всех таблицах |
| Не менее 3 представлений | 4 представления |
| Не менее 3 хранимых процедур | 4 процедуры |
| Не менее 3 функций | 4 функции |
| Не менее 3 триггеров | 4 триггера |
| Главное окно — журнал | `app/forms/main_window.py` |
| Формы справочников с обновлением без выхода | `app/forms/dictionaries.py` |
| Заселение/выселение с автозаполнением PK | `app/forms/checkin.py` (PK генерируются IDENTITY автоматически) |
| Отчёт по выбираемому периоду с параметрами | `app/forms/report.py` (период + категория + сотрудник) |
| Экспорт отчёта в Word и печать | `app/reports/word_export.py` + кнопки «Экспорт» и «Печать» |
